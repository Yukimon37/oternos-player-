# OTERNOS

OTERNOS is a personal Windows desktop music player in active migration from the
legacy Tkinter app to the newer PySide6 Qt shell.

## Friend Download

Use the GitHub Releases page for the friend build:

https://github.com/Yukimon37/oternos-player-/releases/latest

Download the asset named like:

```text
OTERNOS-v0.1.0-win64-portable.zip
```

Do not use GitHub's automatic `Source code.zip` as the app download. Extract
the portable zip first, then run `START_OTERNOS.bat` or `oternos_qt.exe`.
